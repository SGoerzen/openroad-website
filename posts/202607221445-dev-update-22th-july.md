# # Dev Update 22th July

*202607221445* — ser.ragnar

Hello @everyone ,
 this week we has made some good progress. As the results look promising we are highly motivated - but see yourself 🚀 .
## 🕹️ Gameplay
- **Login** [(Video)](https://youtu.be/zljJNShKdMI) to real server. Transition to char selection and afterwards spawn in world while communicating with world server.
- **Monster and NPC Spawn** [(Video)](https://youtu.be/IWYjpiWk8o4): using the server connection NPCs and Monsters are spawn in the world.
- **Monster and NPC Hover** [(Video)](https://youtu.be/ydx97nCIj0A): monsters and NPCs can be hovered and information can be fetched from the server (e.g. name and health).
- **Multiplayer** [(Video)](https://youtu.be/XMU7K0uP5Yo): multiple players can login and run around the world.
- **Inventory and Equipment** [(Video)](https://youtu.be/XLaJANv0-2w): inventory is working, now. The player can equip items and move them inside the inventory.
- **ESC Menu**: Created ESC menu (screenshot).
## 🗺️ Terrain
- **Object navigation and collision** [(Video)](https://youtu.be/taGdO6vYXxg): fixed movement on objects like bridges by using object navmesh. This enables also collision with world objects.
- **Minimap** [(Video)](https://youtu.be/tCrp24DUnHg): the small minimap in the top right corner is rendered. Mobs are shown red and NPCs blue.
- **Shadows** (Screenshot): Instead of realtime shadows, we applied shadow maps to get the classic look.
